# Trinity Installer

Installs Trinity Engine on a Steam Frame: pairs with the headset over Valve's devkit protocol, pushes the latest Frame release and your own Quake III Arena paks, registers the library shortcut and Trinity's SteamVR settings, and installs the library artwork.

Requires Developer Mode on the headset and a Quake III Arena install on this PC. Builds with Go 1.25 and a C compiler (Fyne).

On Windows, choose "More info > Run anyway" if SmartScreen warns about the unsigned download.
